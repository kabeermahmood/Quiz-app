# JavaScript Fundamentals Quiz

An interactive multiple-choice quiz app built with vanilla JavaScript. No frameworks, no libraries — just HTML, CSS, and ES6 JavaScript.

## Features

- 10 questions covering JavaScript fundamentals (variables, arrays, objects, functions, ES6 syntax)
- Start screen with quiz description and start button
- Progress bar showing current question position
- Immediate answer feedback — correct answers turn green, wrong answers turn red
- Buttons lock after answering to prevent multiple selections
- "Next Question" button appears only after answering
- Results screen with final score, percentage, motivational message, and per-question review
- Restart button shuffles questions for a fresh experience each time
- Fully dynamic — no page reloads, everything rendered via JavaScript
- Responsive design — works on desktop and mobile

## How to Run

1. Clone or download this folder.
2. Open `index.html` in any modern web browser.
3. That's it — no build tools or servers needed!
